🔑 Connect Your Deriv Account

Deriv now needs 2 things (their new API, as of 2026):
1. App ID — go to developers.deriv.com → log in → Register new application (any name, any redirect URL like https://tygafinacials.netlify.app works) → copy the App ID it gives you.
2. API Token — generate this from developers.deriv.com itself, under that same registered app (not the old app.deriv.com → Settings → API Token page — that issues a legacy-format token that won't authorize here). Use a demo token first.

You don't need to find your Login ID yourself — once you enter the App ID and token, the app looks up the real account ID directly from Deriv (the new API uses a different ID format than the one shown in app.deriv.com, which is what caused "account not found" errors before).

⚠️ Enable Live Execution

When ON, every new BUY/SELL signal automatically opens a matching Multiplier position on your connected Deriv account — stop-loss and take-profit set from your Account risk %. This is real money if you connected a real account. Off by default, and turns itself back off if the token stops working.

This only executes on Deriv — the same platform the signals' price feed comes from — for any pair currently shown (forex, metals/crypto, and synthetics all trade on Deriv via Multipliers). It cannot place trades on Weltrade; there's no public API for that, so Weltrade-side trades still need a Windows VPS running MT5 with an Expert Advisor — that's the one remaining piece if you want Weltrade itself automated too.
